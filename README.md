# Retail Supply Chain Analytics

## Project Overview

This project analyzes retail supply chain data to understand demand patterns,
inventory performance, stockout risks, and overstock situations.

The project includes data cleaning, exploratory data analysis,
feature engineering, demand forecasting, and Power BI visualization.

## Project Objectives

- Clean and prepare the retail supply chain dataset.
- Perform exploratory data analysis (EDA).
- Engineer features related to inventory and demand.
- Build a basic demand forecasting model.
- Create an interactive Power BI dashboard.
- Provide business insights and recommendations.
